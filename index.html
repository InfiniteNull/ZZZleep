ZZZleep Desktop Application (v1.2.0)

High-performance desktop time-management tool: Indonesian public holidays & long weekend detector, smart alarms with math challenge, Pomodoro circular progress rings, 7-day focus analytics, and mini floating widget mode.

Native Desktop Screenshots (Tkinter GUI)

Technical Architecture & Key Features

  • • Indonesian Public Holidays (2025-2027): Built-in SKB 3 Menteri holiday database with red highlight tags and automated Long Weekend streak detection.
  • • Smart Alarms: Dual spinbox time picker, holiday skipping toggle, and optional Math Challenge solver to dismiss alarm.
  • • Weekly Focus Analytics: Lightweight Canvas 7-day session bar chart tracking completed Pomodoros without external plotting libraries.
  • • Mini Floating Widget: Instant PIP mode (always-on-top overlay) for unobtrusive desktop timer monitoring.
  • • Synthesized Audio Tones: 5 distinct harmonic frequencies generated via winsound.Beep.

Download & Build Instructions

# Option 1: Direct single-file executable download:
Download bin/ZZZleep.exe (12.2 MB) ↗
# Option 2: Run directly from Python source:
git clone https://github.com/InfiniteNull/ZZZleep.git
cd ZZZleep
python desktop/app.py
# Option 3: Compile via PyInstaller:
pip install pyinstaller
python desktop/build_exe.py
