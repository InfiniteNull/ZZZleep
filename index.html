ZZZleep Desktop Application

Aplikasi kalender offline, alarm audio sintetis, timer Pomodoro 25/5, dan pengingat istirahat layar (aturan 20-20-20) untuk laptop dan PC Windows. Berjalan secara lokal tanpa ketergantungan file audio eksternal dan dapat dikompilasi menjadi berkas .exe mandiri.

Tampilan Asli Aplikasi Desktop (100% Native Tkinter)

Audio Alarm Sintetis

Menghasilkan nada alarm secara langsung melalui modul winsound.Beep pada background thread tanpa membutuhkan file audio eksternal (.mp3/.wav).

Aturan Istirahat Mata 20-20-20

Timer otomatis setiap 20 menit menatap layar untuk mengingatkan jeda 20 detik melihat objek sejauh 6 meter (20 kaki) guna mengurangi kelelahan mata digital.

Penyimpanan Lokal JSON

Seluruh jadwal dan preferensi alarm tersimpan di ~/.zzzleep_desktop_data.json secara otomatis dan dapat dicadangkan kapan saja.

Cara Menjalankan & Kompilasi (.exe)

Jalankan langsung melalui Python atau buat file executable mandiri:

# 1. Clone repositori & jalankan aplikasi langsung
git clone https://github.com/InfiniteNull/ZZZleep.git
cd ZZZleep
python desktop/app.py
# 2. Kompilasi menjadi file ZZZleep.exe mandiri
pip install -r requirements.txt
python desktop/build_exe.py
