ZZZleep Desktop Application

Aplikasi manajemen waktu offline untuk laptop dan PC Windows: alarm audio sintetis (winsound), timer Pomodoro 25/5, pengingat istirahat mata 20-20-20, dan penyimpanan data lokal JSON. Tidak memerlukan file audio eksternal dan dapat dikompilasi menjadi file .exe mandiri via PyInstaller.

Tangkapan Layar Asli Aplikasi Desktop (Tkinter GUI)

Spesifikasi & Fitur Teknis

  • • Audio Sintetis: Menggunakan modul winsound.Beep pada background thread tanpa ketergantungan file suara eksternal (.mp3/.wav).
  • • Pengingat Layar 20-20-20: Interval timer 20 menit untuk jeda 20 detik melihat objek sejauh 6 meter guna mencegah kelelahan mata.
  • • Timer Pomodoro (25/5): Siklus fokus kerja dan jeda istirahat dengan notifikasi suara.
  • • Penyimpanan Lokal: Berkas data disimpan di ~/.zzzleep_desktop_data.json.

Cara Menjalankan & Build .EXE

# Jalankan langsung dengan Python:
git clone https://github.com/InfiniteNull/ZZZleep.git
cd ZZZleep
python desktop/app.py
# Kompilasi menjadi ZZZleep.exe:
pip install -r requirements.txt
python desktop/build_exe.py
